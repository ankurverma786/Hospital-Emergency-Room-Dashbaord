#  Hospital Emergency Room Dashboard

##  Project Overview

This project is an interactive **Hospital Emergency Room Dashboard** created in **Microsoft Excel** to analyze patient data and generate meaningful healthcare insights.

The dashboard helps track patient attendance, wait times, satisfaction scores, admission status, department referrals, gender distribution, and age group analysis.

---

#  Objectives

* Analyze hospital emergency room patient data
* Monitor patient admission and attendance trends
* Identify department referral patterns
* Track patient satisfaction and waiting time
* Build an interactive and user-friendly dashboard in Excel

#  Key Insights

* Total Patients Analyzed: **513**
* Average Wait Time: **36.32 Minutes**
* Patient Satisfaction Score: **4.96**
* Admitted Patients: **52%**
* Non-Admitted Patients: **48%**
* Most patients attended on time
* Male patients were slightly higher than female patients
* Highest referrals came from:

  * General Practice
  * Orthopedics
* Most patients belonged to:

  * 01–09 age group
  * 50–69 age group
